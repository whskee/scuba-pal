## Quick Start
1. Start PostgreSQL:
   - `cd scuba-pal`
   - `docker compose up -d`
2. Run the app:
   - `./mvnw spring-boot:run`
3. Open:
   - UI: `http://localhost:8080`
   - API sample: `http://localhost:8080/api/posts`
